# Глобальный поиск и верхняя панель чата (2026-08-27, synthos 0.1.0)

Верхняя часть страницы `syn_chat` была двумя рядами: строка-заглушка
(«Search in inbox..», «?», «Usage and plan» — ни одна из кнопок ничего не
делала) и шапка чата. Первый ряд удалён, второй переработан в одну строку,
а поиск стал настоящим — сквозным по всему приложению.

```
┌────────────────────────────────────────────────────────────────────────┐
│ [НЧ] Новый чат        [🔍 Поиск по приложению      Ctrl K]   ⤢  ␥  🗑 │
│      qwen3.8-27b.syn                                                   │
└────────────────────────────────────────────────────────────────────────┘
```

* Слева — аватар, название (двойное назначение: клик → inline-rename) и имя
  загруженного бандла.
* По центру — пилюля поиска, растянутая на всё свободное место.
* Справа — сжать контекст / очистить ленту / удалить чат. Удаление теперь,
  как и корзина в списке чатов, поднимает диалог подтверждения, а не сносит
  чат сразу.

## Архитектура

```
lib.rs::run              → search::install()          // контекст + эффект индекса
lib.rs::build_app        → search::hotkey_scope(shell) // Ctrl+K / Ctrl+F
                         → search::panel::view()       // PopupPanel в overlay-слое
pages/syn_chat/chat_header → search::trigger::view()   // пилюля
```

| Файл | Что делает |
|------|------------|
| `search/mod.rs` | `SearchCtx` (сигналы), открытие/закрытие, клавиатура, якорь панели |
| `search/model.rs` | `SearchKind` / `SearchItem` / `SearchAction` / `SearchCommand` |
| `search/matching.rs` | нормализация, смена раскладки, скоринг, подсветка |
| `search/index.rs` | сборка индекса из сигналов + фоновое чтение диска |
| `search/actions.rs` | что происходит по Enter |
| `search/panel.rs` | панель: поле, чипы групп, выдача, подвал |
| `search/trigger.rs` | пилюля в шапке |
| `components/event_hook.rs` | прозрачная обёртка: перехват клавиш + отчёт о геометрии |

## Что индексируется

| Группа | Источник | Enter | Shift+Enter |
|--------|----------|-------|-------------|
| Чаты | `SynChatCtx.chats` | открыть чат | — |
| Сообщения | все `~/.config/synthos/syn_chats/*.json` | открыть чат и подсветить сообщение | открыть чат |
| Разделы | маршруты + вкладки настроек | перейти | — |
| Команды | `index::COMMANDS` (16 шт.) | выполнить | — |
| Модели | `.syn` в `models_dir` и закладках SynExplorer | открыть в SynExplorer | загрузить в чат |
| Скилы | `AppCtx.skills` | Настройки → Скилы | — |
| Инструменты | `Tool::all()` | правая панель «Инструменты» | включить/выключить |
| Шаблоны | `templates::list_all()` | открыть вкладкой node-редактора | — |

Индекс собирается эффектом: подписан на сигналы (чаты, скилы, язык UI) и на
`SearchCtx.scan`. Диск читает фоновая задача `SearchCtx::rescan`, которая
запускается при каждом открытии панели — иначе только что написанное
сообщение находилось бы лишь после перезапуска. Пока она работает, в панели
висит плашка «Читаем чаты…».

Потолки (`index.rs`): 6000 сообщений, 600 символов на сообщение, 500
`.syn`-файлов. Тела `tool_call` / `tool_result` в индекс не идут — это
машинный шум, который забивал бы выдачу.

## Ранжирование (`matching.rs`)

Запрос режется на токены; **каждый** обязан найтись хоть в одном поле
элемента (заголовок, подзаголовок, подсказка, ключевые слова). Веса:
точное совпадение 100 → префикс 90 → начало слова 80 → вхождение 60 →
компактная подпоследовательность 30 («рдкт» → «редактор»). Заголовок даёт
+12, подзаголовок +4, длинные заголовки штрафуются.

Запрос дополнительно прогоняется через смену раскладки (`yjls` → `ноды`) со
штрафом −8, поэтому прямое совпадение всегда выше. Если выдачу вытянула
именно смена раскладки, панель показывает плашку с исправленным запросом.

Совпадение по скрытому полю (ключевое слово, id, название чата) выносится в
подпись строки — иначе непонятно, почему строка нашлась.

## Клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl+K`, `Ctrl+F` | открыть / закрыть панель на любой странице |
| `↑` `↓`, `PgUp` `PgDn` | навигация по выдаче (по кругу) |
| `Ctrl+Home` / `Ctrl+End` | первая / последняя строка |
| `Enter` | основное действие |
| `Shift+Enter` | второе действие (см. таблицу выше) |
| `Ctrl+←` / `Ctrl+→` | переключение фильтра-группы |
| `Backspace` при пустом запросе | сбросить фильтр |
| `Esc` | закрыть |

Клавиши ловит `EventHook` — одна обёртка снаружи карточки и одна невидимым
последним ребёнком: при открытом оверлее дерево обходит детей с конца, и
стрелки достаются панели раньше, чем полю ввода.

## Мелочи, о которые легко споткнуться

* **Прозрачность окна.** При `window_opacity < 1` тема делает все `--bg-*`
  полупрозрачными. Карточка панели поэтому красится в `--surface-hover` —
  эту переменную `surface_alpha_mss` не трогает, и сквозь выдачу не видно
  ленту чата.
* **Якорь.** Панель прижимается левым верхним углом к пилюле, так что поле
  ввода ложится ровно на неё. Если пилюли на экране нет (открыли с нод или
  редактора кода), панель центрируется по ширине окна — размер окна берётся
  из `root_bounds`, куда его пишет `hotkey_scope`.
* **Недавнее** живёт в `AppConfig.search_recent` (до 8 ключей) и
  показывается при пустом запросе вместе с чатами, разделами и командами.
* **Отладка:** `SYNTHOS_SEARCH_OPEN="<запрос>" synthos` открывает панель
  через 3 секунды после старта — для скриншотов и ручной проверки выдачи.

## i18n

42 ключа `search.*` в 14 каталогах (`i18n/*.lang`). Ключевые слова элементов
(`page_keywords`, `settings_keywords`, `CommandSpec.keywords`) намеренно
не локализованы — это ru+en синонимы прямо в коде: они не показываются, а
только расширяют попадание («стекло», «blur», «размытие» → команда Glass).
