## synaptix: `synaptix-image-flux2`

- **Энкодер текста** (`text_encoder.rs`): свой лёгкий декодер Mistral / Qwen3 до
  последнего нужного слоя (30 из 40 у Mistral, 27 из 36 у Qwen3); выход — склейка
  `hidden_states` слоёв 10/20/30 (dev) или 9/18/27 (klein). Слои, не влезшие в
  VRAM, читаются из mmap-источника по одному прямо в forward, копии на хосте нет.
  Паддинг до 512: токенайзер Mistral паддит **слева**, Qwen3 — справа (так в HF;
  строки-паддинги слева получают нули из SDPA).
- **DiT** (`transformer.rs`): размеры из конфига, общая модуляция, SwiGLU, RoPE по
  четырём осям. Модуляция и `norm_out` всегда плотные: NVFP4 на них даёт косинус
  шага 0,81 к эталону, MXFP8 — 0,997.
- **VAE** — общий `AutoencoderKl` (32 канала) + пакет 2×2 и нормировка статистикой
  BatchNorm.
- **Референсы**: токены картинок идут в ту же последовательность с `t = 10, 20, …`.
- Стадии `Flux2Model`: `encode_prompt`, `encode_references`, `load_transformer`,
  `sample` (отмена, img2img-заготовка `init`), `decode`.

**Сверка с diffusers 0.40** (`tests/reference.rs`, эталоны —
`scripts/reference/gen_flux2_*.py`, CPU F32): klein-4B — токены бит в бит,
эмбеддинги промпта косинус 0,9999, шаг DiT BF16 0,99988 / MXFP8 0,996 / NVFP4
0,973, VAE совпадает, полная генерация 512² с тем же шумом: BF16 PSNR 40 дБ.
dev — эмбеддинги Mistral косинус 0,99994 против послойного эталона (эталонные
токены пришлось брать из «сырого» `tokenizers`: transformers 5.12 грузит этот
токенайзер как `LlamaTokenizer` и теряет пробелы).

## Память: всё работает при 7 ГБ VRAM

`tests/low_vram.rs` (оба крейта): балласт в VRAM оставляет модели 7 ГБ,
фоновый поток ловит минимум свободной памяти. 1024²:

| модель / веса DiT | что стримится | время | минимум свободной из 7 ГБ |
|---|---|---|---|
| klein-4B NVFP4 / MXFP8 / BF16 | BF16: 16 из 25 блоков с хоста | 4 шага 2–3 с | ~1,2 ГБ |
| klein-9B NVFP4 / BF16 | BF16: 30 из 32 с хоста; энкодер 15/27 слоёв из mmap | 4 шага ~5 с | ≥ 1,0 ГБ |
| dev NVFP4 | 55 из 56 блоков с хоста, Mistral 28/30 слоёв из mmap | 28 шагов 115 с, энкодер 6,5 с | 1,27 ГБ |
| FLUX.1-dev NVFP4 / MXFP8 / BF16 | T5 13/24 блоков из mmap, DiT частично с хоста | 20 шагов 13 / 16 / 28 с | ≥ 0,67 ГБ |

Не влезшие блоки DiT держатся пиннованной копией на хосте (квант один раз при
загрузке); если и RAM не хватает (`MemAvailable` < объём + 12 ГБ) — читаются из
mmap-источника на каждом шаге. Следующий блок едет на loader-стриме во время
счёта текущего.

**FLUX.1 доработан под то же:** T5-XXL стримит блоки из источника
(`T5Encoder::load_budgeted`), квантованный DiT больше не кладётся на карту целиком
(`FluxTransformer::load_budgeted`), префетч блоков в forward (`stream_each`),
перед VAE и энкодерами пулы возвращаются драйверу (раньше на VAE 1024² в 7 ГБ
оставалось 0,03 ГБ).

## synthos: ноды «Нейро → FLUX.2»

- **FLUX.2 Checkpoint** — бандл/каталог, устройство, веса DiT
  `nvfp4 | mxfp8 | dense (bf16)` (по умолчанию mxfp8), память
  `auto | resident | block_offload`, «Держать в памяти».
- **FLUX.2 Text Encoder** — промпт → кондиционирование; повтор с тем же промптом
  берёт готовое (у dev энкодер — Mistral-24B).
- **FLUX.2 Reference** — картинка → токены для правки (площадь до 1 Мп, стороны
  кратны 16); цепочкой через вход/выход `references`, до 10 штук.
- **FLUX.2 Sampler** — шаги (0 — по модели: dev 50, klein 4), guidance (dev —
  эмбеддинг, klein base — CFG, дистиллированный klein игнорирует), seed; размер —
  с FLUX Empty Latent или с первого референса.
- **FLUX.2 VAE Decode** — картинка с превью.

Empty Latent — общий с FLUX.1. Шаблоны (раздел «Картинки»):
`builtin-flux2-text-to-image`, `builtin-flux2-edit`, `builtin-flux2-multi-reference`.
Агент: подсказки `*_idx` FLUX.2, формат промпта `agent/tools/flux2_prompt.md` при
открытии шаблона, каталог инструментов упоминает правку по референсам; прогон из
чата прикладывает PNG из FLUX.2 VAE Decode, если Image Save нет.

Смоук без GUI (настоящие `on_run` нод):

```sh
cargo run --release --bin flux2_smoke -- ~/Storage/syn_models/flux.2-klein-4b.syn out.png 1024 1024
# FLUX2_EDIT=src.png [FLUX2_EDIT2=…] — правка; FLUX2_VRAM_GB=7 — «малая карта»;
# FLUX2_QUANT=nvfp4|mxfp8|dense, FLUX2_REPEAT=2 FLUX2_RESIDENT=1
```
