# Режим «Заметки» (2026-09)

Notion/Obsidian-редактор поверх vault-папки на диске. Открывается плитками
нав-рейла (по плитке на открытую страницу, как чаты); слева — дерево vault,
в центре — редактор, справа — вкладки «Вставка | Свойства | Связи».

## Хранение (гибрид)

Vault — обычная папка (`AppConfig.notes_vault_path`, дефолт
`~/Documents/SynthOS Notes`), файлы переносимы и читаются извне:

| Файл             | Содержимое                                   | Редактор                    |
|------------------|----------------------------------------------|-----------------------------|
| `*.md`           | страница, расширенный markdown               | `syngui::DocumentEditor`    |
| `*.base.json`    | база: колонки/строки/представления           | `pages/notes/base/`         |
| `*.canvas.json`  | канвас: карточки + рёбра + камера            | `pages/notes/canvas/`       |

Ключ страницы всюду — vault-относительный путь с расширением; плитка рейла —
`note:<rel>`; спец-плитка графа — `:graph`.

Вложения — общий CAS чатов (`~/.config/synthos/blobs`), в markdown — ссылки
`blob:<sha256>.<ext>` (`pages/notes/media.rs`; GC чатов учитывает ссылки
vault'а). Внешний файл, брошенный в страницу, вставляет pending-блок,
фоновый ingest подменяет его через `handle.patch_media` + `media_epoch`.

## Расширенный markdown (парсер/сериализатор в syngui)

`syngui/src/widgets/input/document_editor/{parse,serialize}.rs`:
pulldown-cmark + пост-проходы. Нормализованный вывод, идемпотентный со
второго прохода (корпус фикстур `syngui/tests/document_roundtrip.rs`).

- `[[Цель]]` / `[[Цель|алиас]]` — wiki-ссылки; `![[Цель]]` отдельной
  строкой — живая врезка (страница read-only, база/канвас — редактируемые,
  глубина ≤ 2, циклы отсекаются);
- `> [!kind]{color=#…} Заголовок` — callout; `[!toggle]` — сворачиваемый
  блок (`{open}` — развёрнут);
- инлайн-атрибуты хвостом: `## Заголовок {icon=🚀}`,
  `![видео](blob:…mp4){loop width=70%}`;
- медиа-блоки: картинки (ImageStore), видео/аудио-плееры (ffmpeg;
  `media_block.rs`), файлы; всё «инлайновое» медиа при парсе становится
  блоком (Notion-модель).

Известные нормализации: soft-break → пробел, литеральный `{k=v}` в конце
заголовка становится атрибутами, пустые блоки не переживают сериализацию.

## Редактор (syngui, feature `document-editor`)

«Пассивные строки»: блоки — дочерние элементы (виртуализация/культинг),
весь ввод — у контейнера (каретка/выделение/IME/undo). Геометрия строк
публикуется в общий реестр — по нему хит-тест, каретка, выделение.

- slash-меню «/», markdown-шорткаты набора, инлайн-тулбар, автокомплит
  `[[` (DocLinkProvider), Ctrl+клик открывает ссылку;
- undo/redo — снапшоты с группировкой набора (~700мс);
- Tab/Shift+Tab — отступы списков; ручка ⋮⋮ — перетаскивание блоков;
- инъекции хоста: `DocLinkProvider`, `DocMediaResolver`, `EmbedFactory`,
  `on_drop_file`; `DocumentEditorHandle` — общая модель + `revision`
  (автосейв), `serialize()`, `append_markdown()`, `patch_media()`;
- MSS: элемент `document-editor`, переменные `--doc-*`
  (`styles/components/notes.mss` маппит на токены темы).

## Автосейв и watcher

`autosave.rs`: эффект подписан на ревизии открытых страниц (и пула врезок),
фоновый поток пишет после ~700мс тишины (атомарно, tmp+rename); свои записи
помечаются на 2с — `fs_watcher.rs` (notify, дебаунс 300мс) их игнорирует.
Внешняя правка: чистая страница перечитывается тихо, грязная — жёлтый
баннер «Перечитать / Перезаписать». Структурные события пересканируют
дерево и индекс.

## Связи и граф

`index.rs` — лексер `[[целей]]` по сырому md (fenced-код пропускается),
резолюция по имени/пути, backlinks; обновляется на каждое сохранение.
Вкладка «Связи» — backlinks/исходящие + мини-граф (≤2 хопа). Полный граф —
спец-плитка: force-layout (Фрухтерман–Рейнгольд) в `animate`, клик
открывает страницу, drag прибивает узел.

## Базы и канвасы

База: `BaseHandle` с двумя ревизиями (`revision` — автосейв,
`structure_rev` — перестройка UI, чтобы набор в ячейке не ронял фокус);
представления Таблица (TableView + инлайн-редакторы), Канбан
(Draggable/DropArea, группировка по select), Ганнт (шкала, драг/ресайз
баров, зависимости). Канвас: `CanvasHandle` + runtime-сигналы позиций/
размеров/редакторов карточек, PanZoomViewport, рёбра-безье со стрелками.

## Точки расширения LLM (задел)

- `DocumentEditorHandle` — программные правки документа
  (`serialize`/`append_markdown`/`patch_media`) — сюда встанут
  AI-команды «продолжить/суммаризировать»;
- `DocumentEditor::slash_items` + `on_slash_custom` — пункты меню «/»
  от хоста (в т.ч. будущие AI-действия);
- `VaultIndex` — контекст для RAG по заметкам;
- вкладка «Вставка» (`right_panel.rs`) — место для «спросить модель».

## Тесты

syngui: `document_roundtrip` (корпус фикстур), `document_editor_widget`
(30 headless-сценариев редактирования), юниты attrs/linebox/edit/shortcuts.
synthos: юниты index/media/base/canvas/gantt + страж-тесты
(i18n_catalog_coverage, mss_variable_coverage, icons_font_coverage).
