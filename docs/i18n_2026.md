# Мультиязычность интерфейса (2026-08)

Интерфейс переключается между 14 языками без перезапуска: en, ru, de, fr, es,
it, pt-BR, pl, uk, kk, tr, zh-CN, ja, ko. Ядро — `syngui::i18n`
(`../syngui/docs/15-i18n.md`); здесь — как это подключено в synthos.

## Архитектура

```
AppConfig.general.language  ("auto" | тег, ~/.config/synthos/config.json)
        │  lib.rs::build_context → GeneralCtx.language: RwSignal<String>
        ▼
i18n::install(general)            src/i18n/mod.rs
   ├─ register_catalogs(CATALOGS) — 14 × include_str!("../../i18n/<tag>.lang")
   └─ create_effect: "auto" → syngui::i18n::system_language(), иначе Lang::new(tag)
        │
        ▼
syngui::i18n::set_language(lang)  → цепочка [тег, база, en] + сигнал ревизии
        │
        ▼
lib.rs::run: DecoratedBox.child(|| { syngui::i18n::subscribe(); build_app() })
        │  корень подписан на ревизию → при смене языка оболочка реконсилируется
        │  in-place (RouterView перестраивает активную страницу)
        ▼
tr!("settings.general.title") внутри любого билдера → строка из каталога
```

Персист: `AppConfig.general.language`, дефолт `"auto"` (язык системы: `LC_ALL`,
`LC_MESSAGES`, `LANG`, `LANGUAGE`; на этой машине `ru_RU.UTF-8` → `ru`). Старые
конфиги со значением `"ru"` продолжают открываться по-русски.

Переключатели: глобус в нижнем кластере нав-рейла (`components/nav_rail.rs::
language_button`, `PopupMenu` со списком `syngui::i18n::languages()` + пункт
«как в системе») и дропдаун «Язык интерфейса» в Настройки → Общие
(`i18n::language_items()`). Оба пишут в `GeneralCtx.language`.

## Каталоги

`i18n/<tag>.lang`, формат `key = "value"` (см. `../syngui/docs/15-i18n.md`).
`en.lang` — источник, `ru.lang` — полный зеркальный; остальные 12 —
машинные черновики, выверенные только на ключи и плейсхолдеры. Что нет в языке,
берётся из `en`.

Ключи: `<область>.<компонент>.<элемент>[.<квалификатор>]`:

| Префикс | Область |
|---|---|
| `app.*` | общие действия (`app.close`, `app.cancel`, …) |
| `nav.*` | нав-рейл, `nav.language.auto` |
| `settings.tabs.<key>.*`, `settings.<tab>.*` | настройки; описание строки — тот же ключ + `.desc` |
| `chat.*` | Syn-чат: лента, панель ввода, правая панель, карточки прогонов |
| `nodes.*` | хром нодового редактора (вкладки, прогон, меню) |
| `node.category.*`, `node.subcategory.*`, `node.<kind>.title`, `node.<kind>.*` | реестр и тела нод; `<kind>` — serde-имя `NodeKind` |
| `nodes.common.*` | строки, общие для многих нод |
| `template.category.*`, `template.<id>.name`, `template.<id>.desc` | встроенные шаблоны по `id` |
| `explorer.*`, `hf.*`, `code.*`, `voice.*`, `kb.*`, `skills.*`, `models.*`, `notify.*` | остальные страницы |
| `tool.<key>.label` | подпись инструмента агента в UI |

Хелперы для строк, которые берутся не литералом, а по данным
(`src/i18n/mod.rs`): `node_title(meta)`, `node_category_label`,
`node_subcategory_label`, `template_name`, `template_description`,
`template_category_label`, `tool_label`. Все — `try_tr` с фолбэком на литерал
из кода, поэтому неполный каталог не ломает интерфейс.

## Что не переводится

- `NodeKind` (serde-имена), `PortSchema.name`/`label`, `FieldSchema.name`/`label`,
  `id` шаблонов, ключи маршрутов и вкладок, значения конфига, dtype/устройства,
  имена файлов и репозиториев, пользовательские данные (названия чатов, шаблонов,
  сессий).
- Тексты для модели: системный промпт, описания инструментов, результаты
  инструментов, промпты компактификации — они на английском и не переключаются
  (`tests/i18n_agent_english.rs` следит, чтобы кириллица туда не вернулась).
- Логи `tracing`/`log`.

## Как добавить строку

1. В коде: `Text::new(tr!("chat.input.placeholder"))`, с аргументами —
   `tr!("hf.download.done", name = file)`, счётчики — `trn!("hf.files", n)` с
   формами `.one/.few/.many/.other` в каталоге.
2. В `i18n/en.lang` и `i18n/ru.lang` — одна строка `key = "…"` в каждом.
3. `cargo test --test i18n_catalog_coverage` — ключ найден в исходниках и в обоих
   каталогах, плейсхолдеры совпадают. Остальные языки можно дополнить позже:
   пропуск покажется предупреждением, а не ошибкой.

Строка обязана строиться внутри билдера (`view()`, `Reactive`, `.child(|| …)`):
литерал, вычисленный один раз в `const`/`static`, языка не сменит. Для таблиц
хранят ключ (`tooltip_key`) и зовут `tr!` при построении.

## Как добавить язык

Файл `i18n/<tag>.lang` с `@tag`, `@name` (родное название), при необходимости
`@plural` (правила: `one-other`, `zero-one-other`, `east-slavic`, `polish`,
`other-only`); добавить `include_str!` в `CATALOGS` (`src/i18n/mod.rs`).
Переключатели подхватят язык из `syngui::i18n::languages()` сами.

## Шрифты

Латиница и кириллица — основной шрифт. Для zh-CN/ja/ko syngui подбирает
системное семейство по письменности (Noto Sans CJK, Source Han Sans, PingFang,
Microsoft YaHei, Malgun Gothic…) при первом непокрытом символе; `.ttc` читается
один раз. Вариант иероглифов (SC/JP/KR) выбирается по языку интерфейса. Арабское
письмо, деванагари и RTL не поддерживаются — шейпинга во фреймворке нет.

## Известные ограничения

- Уведомление, показанное до переключения, остаётся на прежнем языке.
- Локальные `use_signal` внутри `view()` (например выбранный раздел пикера
  шаблонов) сбрасываются при смене языка; контексты, PTY-сессии, стримы чата,
  черновики в полях и раскрытые дропдауны сохраняются.
- Числа форматируются через `format!` — разделитель дробной части `.`.
- Скопированный пользователем шаблон (`duplicate_to_custom`) и заголовки вкладок
  в `workspace.json` хранят текст на том языке, в котором были созданы.
