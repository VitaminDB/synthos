# Оболочка: плитки в рейле, общая шапка, трёхпанельный каркас, архив чатов (2026-08-27, synthos 0.1.0)

До этой переделки у каждой страницы была своя верхняя часть: у чата — шапка с
поиском и колонка чатов слева, у нод — полоса вкладок, у пакетов — toolbar, у
HF — трёхстрочная шапка, у редактора кода — ничего. Глобальный поиск (`Ctrl+K`)
был виден только в чате. Рейл показывал только code-сессии, а «+» в нём всегда
создавал редактор кода.

Теперь оболочка одна на все страницы: три колонки, у каждой — свой заголовок
одной высоты (52px), выровненные в одну строку:

```text
┌──┬───────────────────────┬──────────────────────────────────────────┬───────────────────┐
│S │ ▤ [ик] Левая панель   │ [ик] Заголовок  [🔍 Поиск  Ctrl K]  ⋯    │ Правая панель   ▥ │ ← panel_header × 3
│──│                       │      подзаголовок                        │                   │
│▤ │ тело левой панели     │ центр                                    │ тело правой       │ ← workspace_frame
│⬡ │                       │                                          │                   │
│AB│                       │                                          │                   │
│─ │                       │                                          │                   │
│⬡ │                       │                                          │                   │
│+ │                       │                                          │                   │
│  │                                                                                      │
│▣ │  рейл: плитки code-сессий (▤), графов (⬡), чатов (AB), разделители (─)               │
│☁ │  и «+» → меню: Редактор кода · Нодовый редактор · Чат · Разделитель                  │
│⚙ │                                                                                      │
└──┴──────────────────────────────────────────────────────────────────────────────────────┘
```

Тоггл левой панели (▤) стоит у левого края её заголовка, правой (▥) — у
правого края её заголовка; когда панель скрыта, тоггл переезжает к тому же
краю центрального заголовка, чтобы панель можно было вернуть.

## Рейл (`components/nav_rail.rs`, `rail.rs`)

Верхних иконок-разделов «Чат» и «Ноды» нет. Между логотипом и футером — единый
список плиток трёх типов плюс разделители, собранный `rail::entries()`:

| Плитка | Источник | Иконка/вид | Клик | «Закрыть» (контекстное меню) |
|---|---|---|---|---|
| code-сессия | `CodeEditorCtx.sessions` | папка / документ + бейдж терминалов | `switch_to` + маршрут `code` | `CodeEditorCtx::close` |
| граф нод | `EditorWorkspace.tabs` (не `hidden`) | hub / tune (Untitled) / psychology (агентский); «•» в подписи — не сохранён | `activate` + маршрут `nodes` | `request_close`: dirty → диалог, иначе сразу |
| чат | `SynChatCtx.chats` (не `archived`) | аватар с инициалами и tone-цветом, акцентная рамка у активного | `registry::select` + маршрут `syn_chat` | подтверждение → архив |
| разделитель | `AppCtx.rail_separators` | тонкая линия (зона 40×12 для правого клика) | — | удалить |

Порядок — по `created_at` (unix-мс), вперемешку по типам, tie-break по типу и id.
Штампы: `CodeSessionConfig.created_at` (config.json), `TabState.created_at`
(workspace.json), `StoredChat.created_at` (секунды × 1000), сами разделители —
это и есть список штампов `AppConfig.rail_separators`. Конфигам до этой версии
штампы назначаются по позиции в списке при загрузке (`legacy_base + index`),
чтобы прежняя расстановка сохранилась. `reveal` агентского графа из чата
ставит ему `created_at = now` — плитка появляется в конце, где её ищут глазами.

Под каждой плиткой подпись (`.nav-rail-session-label`, 9px, одна строка).
Сегмент лежит в `ScrollView` внутри `.grow`-хоста: при десятках чатов рейл
прокручивается, футер остаётся на месте.

Меню «+» — `PopupMenu` справа от кнопки: `rail::new_code_session` (пустая
сессия + маршрут), `rail::new_graph` (открыть окно шаблонов; плитка появится
после выбора, закрытие окна без выбора ничего не создаёт), `rail::new_chat`,
`rail::add_separator`.

## Заголовки панелей (`components/panel_header.rs`)

Центральный заголовок — `panel_header::center(CenterSpec { identity,
center_extra, actions })`: идентичность слева, пилюля глобального поиска
(`search::trigger`) по центру на каждой странице, действия справа. Боковые —
любой контент страницы (`side_title`, заголовок с кнопкой, TabBar); тогглы
добавляет каркас.

| Страница | Левый заголовок | Центральный: идентичность | Центр: действия | Правый заголовок |
|---|---|---|---|---|
| Чат | «Инструменты» | аватар, название (клик → inline-rename), имя бандла | сжать · очистить · **в архив** | TabBar Параметры / Детали |
| Код | папка сессии + путь, «Открыть папку» | активный файл (иконка типа, dirty-точка), каталог | перенос строк · история · сохранить | «Открытые файлы · N» |
| Ноды | — | иконка по происхождению, название (inline-rename), «Из шаблона: …» / «Черновик» / «Граф агента» · «не сохранено» | Run/Pause/Stop + таймер · Шаблоны · Сохранить как шаблон | — |
| Пакеты | «Закладки» + добавить | имя пакета, путь (или статус) | бывший toolbar | «Файлы пакета N» + извлечь |
| HF | «Модели» | «HuggingFace» | — (в центре ещё поле поиска по Hub) | «Файлы» |
| Настройки | «Настройки» | раздел + его подпись | — | заголовок панели раздела («Скилы +», «Аудио модели +», «Коллекции +») или название раздела |

## Трёхпанельный каркас (`components/workspace_frame.rs`)

`FrameSpec { split_class, left: Option<Pane>, center_header, center, right: Option<Pane> }`;
`Pane { header, body, ratio, visible, min_size }`. Каждая колонка —
`Column[.panel-header [тоггл? | контент | тоггл?], .grow тело]`. Всё тело —
`Reactive` по сигналам `visible`: скрытая панель не строится и не занимает
места, центр растягивается. Разделители — `SplitView` с прежними per-page
ratio-сигналами; линия разделителя проходит и через строку заголовков.

| Страница | Левая | Центр | Правая | ratio (config.json) | видимость (`AppConfig.panels`) |
|---|---|---|---|---|---|
| Чат | Инструменты / Скилы (`syn_chat::left_panel`) | лента + ввод | Параметры / Детали | `syn_chat_*_split_ratio` | `syn_chat_left/right` |
| Код | дерево файлов | редактор ↕ терминал | открытые файлы | per-session `code_sessions[i].*` | `code_left/right` |
| Пакеты | закладки | вкладки пакета | дерево пакета | `syn_explorer_*` | `syn_explorer_left/right` |
| HF | чипы сортировки + список моделей | шапка репозитория + README | файлы и загрузки | `hf_*_split_ratio` (новые) | `huggingface_left/right` |
| Настройки | разделы | контент раздела | скилы / модели / коллекции / подсказка | `settings_*_split_ratio` (новые) | `settings_left/right` |
| Ноды | — | канвас на всю ширину («Модели в памяти» — оверлей) | — | — | — |

Сигналы видимости — `context::PanelsCtx` (пара `(левая, правая)` на страницу),
персист через `install_config_autosave`.

## Графы нод без вкладок

* `tabs_bar.rs` и `node_editor_tabs.mss` удалены; `EditorWorkspace` остался
  (список «вкладок» = плиток), но `new()` / `from_state` / `close` больше не
  досоздают `Untitled`: пустой список — нормальное состояние, страница
  показывает заглушку «Нажмите + → Нодовый редактор».
* `open_template` всегда создаёт новую копию (без дедупликации по `source`);
  повторам даётся подпись «Имя (2)», «Имя (3)» (`tabs::unique_title`).
* Run-пилюля и кнопки шаблонов переехали в шапку; на канвасе остался только
  зум-тулбар и панель «Модели в памяти».
* Закрытие грязного графа — `EditorWorkspace::pending_close` →
  `components::graph_close_dialog` (Сохранить как шаблон / Закрыть без
  сохранения / Отмена). Диалог смонтирован в shell'е: плитку закрывают с любой
  страницы.

## Архив чатов

`StoredChat.archived: bool` (serde default, не пишется, пока `false`).
`registry::archive(id)` — сохранить активный чат, поставить флаг, выбрать
следующий видимый; `unarchive(id)` — снять флаг и активировать;
`clear_archive()` — удалить все архивные файлы + GC вложений. Корзина в шапке
чата, «Закрыть» плитки и команда поиска «Убрать текущий чат в архив» ведут в
`pages::syn_chat::archive_dialog` (тоже в shell'е).

Раздел **Настройки → Архив** (`pages/settings/archive.rs`, маршрут `archive`):
список с аватаром, названием, превью, датой и моделью; «Вернуть» (→ рейл и
страница чата), «Удалить насовсем» (с подтверждением), «Очистить архив».
Архивные чаты и их сообщения в индекс глобального поиска не попадают.

## Что не сделано / на потом

* Хоткеи переключения плиток (Ctrl+Tab, Ctrl+1..9) — по решению пользователя не
  сейчас.
* Drag-reorder плиток в рейле: порядок только по времени создания.
* Левая панель чата пока с одной вкладкой «Инструменты» — каркас с `TabBar`
  готов под соседние вкладки.
* Панели у нод (палитра нод, свойства) — не заложены: решение «без панелей».
