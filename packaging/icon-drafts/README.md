# Черновики иконки Synthos

10 вариантов, все — плоский SVG 512×512 без фильтров и теней. Плитка у всех
одна и та же: суперэллипс (squircle) `|x/224|^4.3 + |y/224|^4.3 = 1`,
аппроксимированный 16 кубическими сегментами — непрерывная кривизна, углы не
«ломаются» на больших размерах.

Базовый коралл — `#EE5E48`, это `--primary` из `styles/base/variables.mss`.

|---|---|
| `01-mono-s.svg`     | Коралловая плитка, белая геометрическая монограмма S |
| `02-graphite-s.svg` | Графитовая плитка, коралловая S |
| `03-knockout-s.svg` | Коралловая плитка, S вырезана насквозь (прозрачная) |

Превью: `_preview-light.png` (на светлом), `_preview-dark.png` (на тёмном),

## Как поставить выбранный вариант

    cp packaging/icon-drafts/NN-имя.svg packaging/synthos.svg
    cargo build --release -p synthos        # SVG вшит в бинарь: nav_rail + «О программе»
    # поднять pkgrel в packaging/PKGBUILD
    cd packaging && makepkg -f && sudo pacman -U synthos-0.1.0-<pkgrel>-x86_64.pkg.tar.zst

## Вариации 5-го варианта (S потолще + ромбовидность)

Скелет тот же — две «чаши» с центрами (248,200) и (248,320), — но окружность
заменена на суперэллипс `|x/R|^p + |y/R|^p = 1`: при `p=2` это круг, при `p=1`
— ромб. Чем меньше `p`, тем острее углы монограммы. Каждая дуга собрана из
8 кубических сегментов с подгонкой по касательной и середине, поэтому кривая
гладкая, а не гранёная.

| файл | p | обводка |
|---|---|---|
| `05a-thick.svg`       | 2.0  | 46 — круглая, просто толще |
| `05b-soft.svg`        | 1.7  | 46 — чуть ромбовая |
| `05c-rhomb.svg`       | 1.4  | 46 — явно ромбовая |
| `05d-rhomb-heavy.svg` | 1.4  | 58 — ромбовая жирная |
| `05e-sharp.svg`       | 1.15 | 50 — почти ромб |

Превью — `_preview-05.png` (256 px и 64 px в том же порядке).
